# AGENTS.md — «Скрипт ролика»

Это второе приложение пользователя, выделенное из «Карточки English» (репозиторий `id314302-dev/cards`). Здесь тренируется дословный английский текст для первого видео на YouTube: куски скрипта, трудные слова, плеер «Повтори за диктором».

**Проект — PWA, а не нативное приложение.** Статический сайт на GitHub Pages, ставится на главный экран Chrome. Не создавай APK, Android Studio, Gradle, Capacitor и подобное, не добавляй сборку и зависимости. Пользователь отвечает по-русски, любит короткие объяснения и один шаг за раз.

- Код — те же `index.html` + `cards.js` + `sw.js`, что в «Карточки English», с двумя колодами: `script` (101 кусок, режим «Тает», подсветка `mk`) и `hard` (30 трудных слов). Подробное устройство движка (модель данных, режимы, плеер, кэш) описано в `AGENTS.md` репозитория `cards`; здесь отличаются только названия, ключи и состав колод.
- Озвучка: `audio/` (американский Jon) и `audio-uk/` (британский Johnny Kid), как в основном приложении. Плеер берёт файлы из `sessions/`, их собирает `tools/build_sessions.py` (нужны PyAV и numpy); пересобирай только при смене озвучки или состава колод.

## Важно: два приложения на одном адресе
Оба сайта живут на `id314302-dev.github.io` (разные папки `/cards/` и `/script/`), поэтому у них **общая память браузера (localStorage) и общее хранилище кэша**:
- **Кэш**: у каждого приложения свой префикс имени (`cards-…` и `script-…`), service worker удаляет только свои кэши. Не меняй префикс и не удаляй чужие кэши, иначе приложения будут стирать офлайн-копии друг друга.
- **localStorage**: `cards-progress-v1` (прогресс карточек) и `cards-habit-v1` (серия дней) **намеренно общие**: время в двух приложениях идёт в одну цель, ключи карточек не пересекаются (`script:N`, `hard:N`, у основного — `core`/`cup:N`). Свои настройки у этого приложения отдельные: `script-prefs-v1`, `script-player-v1`.
- `manifest.json`: `id` `/script/v1`, иконки `icon-v1-*`.

## Ограничения
Репозиторий публичный: секретов нет и быть не должно. Не удаляй и не переименовывай существующие файлы озвучки без согласования. Правки точечные, в стиле окружающего кода. Проверка без браузера: `~/cards-tts/tests/` на сервере пользователя (`CARDS_ROOT=<путь> python player_test.py` / `sw_test.py`).
